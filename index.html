Phase 1 • Days 01–08

Linux Administration & Shell Scripting

Day 01: Linux Foundations & Navigation Architecture, File System Hierarchy (FHS), core commands (`ls`, `cd`, `grep`, `find`, `tar`), and piping.
Day 02: User Management & Permissions User/group administration, POSIX permissions (`chmod`, `chown`), Umask, and Sudoers security.
Day 03: Process Management, Storage & Systemd Process inspection (`ps`, `top`), signal handling, disk storage, swap, and writing systemd service units.
Day 04: Networking, SSH & Security TCP/IP fundamentals, network troubleshooting (`netstat`, `ss`, `ip`, `curl`), SSH keys, and basic firewalls.
Day 05: Package Management & Software Installation APT, YUM/DNF, compiling packages, environment variables, shared libraries, and daemon configuration.
Day 06: Bash Scripting Fundamentals Shell scripts, positional parameters, control loops (`if-else`, `while`), and input validation.
Day 07: Advanced Scripting & Text Processing Stream manipulation with `sed` and `awk`, regular expressions, bash functions, and log parsers.
Day 08: Linux Mini-Project & Review Build an automated server health monitor script that auto-compresses logs and dispatches alerts.
Phase 2 • Days 09–16

Azure Cloud Architecture & Core Services

Day 09: Azure Foundations & Governance Regions, availability zones, subscriptions, resource groups, and Azure Policy.
Day 10: Azure Identity & Access Management (Entra ID) Azure AD / Entra ID, Users, Groups, Role-Based Access Control (RBAC), and Managed Identities.
Day 11: Azure Virtual Networking (VNet) Address spaces, Subnets, Network Security Groups (NSGs), ASGs, and VNet peering.
Day 12: Azure Compute (IaaS) Azure Virtual Machines, VM sizing, disks, VM Scale Sets (VMSS), and auto-scaling.
Day 13: Azure Storage Architecture Blob storage (Hot/Cool/Archive), Azure Files, SAS tokens, and storage firewalls.
Day 14: PaaS Compute & Serverless Azure App Services (Web Apps), deployment slots, and Azure Functions (serverless).
Day 15: Azure Networking & Security Services Azure Load Balancer, Azure Application Gateway (WAF), and Azure Key Vault.
Day 16: Phase 2 Hands-On Lab Deploy a secure, multi-tier web application architecture featuring load balancing and Key Vault.
Phase 3 • Days 17–24

Infrastructure as Code (IaC) with Terraform

Day 17: IaC Concepts & Terraform Basics Declarative IaC, CLI workflow (`init`, `plan`, `apply`, `destroy`), and `azurerm` provider.
Day 18: Terraform HCL Syntax & Resources Blocks, arguments, input variables, output values, locals, and data sources.
Day 19: State Management & Remote State Managing `terraform.tfstate`, remote locking with Azure Blob Storage Lease, and state commands.
Day 20: Expressions, Functions & Loops Built-in functions, conditionals, `count`, `for_each`, and dynamic blocks.
Day 21: Modular Terraform Development Reusable module creation, child vs root modules, and module versioning.
Day 22: Advanced Terraform Operations Workspaces for Dev/Prod environments, importing existing infrastructure, and drift management.
Day 23: Terraform Linting & Security Static code analysis with `tflint`, security scanning with `tfsec`, and formatting checks.
Day 24: Phase 3 Capstone Lab Develop an entire Azure landing zone using custom reusable modules and remote backend state.
Phase 4 • Days 25–32

Containers & Azure Kubernetes (AKS)

Day 25: Docker Fundamentals Container engine, images vs containers, and running lightweight workloads locally.
Day 26: Containerizing Applications Writing multi-stage `Dockerfiles`, caching layers, minimizing image footprint, and best practices.
Day 27: Docker Networking & Storage Bridge networks, volumes vs bind mounts, and multi-service Docker Compose setups.
Day 28: Azure Container Registry (ACR) Setting up ACR, authenticating with service principals, pushing images, and vulnerability scanning.
Day 29: Kubernetes Fundamentals K8s architecture, `kubectl` CLI commands, Pods, ReplicaSets, and Deployments.
Day 30: K8s Networking & Services ClusterIP, NodePort, LoadBalancer services, Ingress controllers, and ConfigMaps/Secrets.
Day 31: Azure Kubernetes Service (AKS) Setup Provisioning AKS clusters via Terraform, node pools, networking types, and RBAC integration.
Day 32: Phase 4 Lab Deploy a microservice app onto AKS with Ingress routing and secure ACR image pulling.
Phase 5 • Days 33–40

Enterprise CI/CD Pipelines

Day 33: Version Control & Git Strategy Branching strategies (Trunk vs GitFlow), Pull Requests, code reviews, and commit hygiene.
Day 34: Azure DevOps & Azure Repos Organization & project setup, Azure Repos, PAT tokens, and cloud service connections.
Day 35: Azure Pipelines (YAML Syntax) Pipeline triggers, agents, stages, jobs, and tasks in modern YAML pipelines.
Day 36: Building CI Pipelines Continuous Integration: automated testing, Docker build tasks, and ACR publishing.
Day 37: CD & Deployment Strategies Release environments, approval gates, blue-green deployments, and canary releases.
Day 38: Automating Terraform via Azure Pipelines IaC automation: linting, planning on PRs, and gate approval before applying changes.
Day 39: Secrets Management in Pipelines Variable groups, Azure Key Vault integration in Pipelines, and secret masking.
Day 40: Phase 5 Lab Build an end-to-end automated Azure YAML pipeline triggering on Git push.
Phase 6 • Days 41–45

DevSecOps, Monitoring & Interview Readiness

Day 41: DevSecOps & Security Automation Vulnerability scanning with Trivy and automated secret detection in pipelines.
Day 42: Azure Monitor & Log Analytics Log Analytics workspaces, Kusto Query Language (KQL) basics, and diagnostic rules.
Day 43: Application Performance Monitoring (APM) Application Insights, distributed traces, metric alerts, and cloud dashboards.
Day 44: Final Capstone Implementation End-to-end execution: Terraform provisioning, CI/CD pipeline, security scans, and monitoring.
Day 45: Capstone Review & Technical Mock Interviews Architecture defense, resume polishing, and technical interview preparation for junior/entry-level DevOps roles.
